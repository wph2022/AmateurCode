寄存器安全验证流程

任何写入都必须建立在身份、属性、回读和恢复机制之上。

写入警示：仅在确认寄存器可写、芯片身份正确、目标值合法并具备恢复方案时执行 WRITE / RMW；只读寄存器禁止写入。

命令与结业实操

训练结果必须能够被复现、检查和归档。

# 检查 ADB 设备
adb devices

# 读取平台与项目信息
adb shell getprop ro.board.platform
adb shell getprop ro.product.model

# I²C 寄存器读取示例（参数必须按芯片配置确认）
adb shell "i2ctransfer -f -y 5 w1@0x6b 0x00 r1"

# 标准结果摘要
INFO | REGISTER | READ | bus=5 addr=0x6B reg=0x00 value=0x95 | PASS
